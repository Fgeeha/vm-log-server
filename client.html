Схема интеграции с Synology NAS

1

Запустить сервер

Установите Node.js и запустите сервер на любой машине в вашей локальной сети.

npm install node server.js # или с указанием пути к CSV: NAS_CSV_PATH=/mnt/nas/logs/audit.csv node server.js
2

Включить SMB-аудит в DSM

DSM → Control Panel → File Services → SMB → Advanced → включить Enable transfer log

Типы событий: ✓ Create ✓ Delete ✓ Read ✓ Write ✓ Rename ✓ Move
3

Syslog real-time (UDP)

DSM → Log Center → Log Sending → добавить сервер. Выберите UDP 514 и формат IETF или BSD.

Destination IP: [IP этого ПК] Port: 514 Protocol: UDP Format: IETF (RFC 5424) Правило iptables (если нет root): sudo iptables -t nat -A PREROUTING \ -p udp --dport 514 \ -j REDIRECT --to-port 5514
4

CSV Polling (автоматический)

Synology экспортирует CSV в общую папку. Сервер читает файл каждые 30 секунд и отправляет только новые строки.

# Примонтировать папку Synology: # Linux: mount -t cifs //192.168.1.100/logs \ /mnt/nas/logs -o user=admin # Windows: net use Z: \\192.168.1.100\logs # Task Scheduler в DSM: # скрипт экспорта каждые 5 минут

Архитектура

Synology NAS ├── SMB Audit Log │ └── UDP Syslog ──────────────→ server.js :514 → WebSocket → этот браузер ├── Log Center CSV export │ └── /shared/logs/audit.csv ──→ server.js poll (30s) → WebSocket → этот браузер └── Ручной экспорт CSV └── ────────────────────────→ вкладка "CSV" → прямо в таблицу
